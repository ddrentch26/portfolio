D&M Detailing Website

A responsive booking site for a mobile car detailing business, translating Figma designs into a live, component-based React UI with real scheduling built in.

Role
Designer & Developer
Tools
React · TypeScript · Tailwind CSS · Figma · Square Appointments API
Status
Live (Booking Paused)

Architected a responsive, multi-page site in React, TypeScript, and Tailwind CSS, translating Figma designs into a reusable, component-based UI.

Integrated Square Appointments as a live booking system via an embedded iframe, with a loading state, a fallback "open in new tab" option for blocked iframes, and a graceful setup-instructions view when unconfigured.
