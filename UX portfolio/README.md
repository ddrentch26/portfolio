# Danail Drentchev; UI/UX Portfolio

A simple, single-page portfolio site.

## Files
- `index.html`; page content
- `styles.css`; all styling
- `script.js`; lightbox + footer year
- `images/`; drop project screenshots + profile photo here
- `resume/`; drop `resume.pdf` here

## To finish setup
1. Add screenshots to `images/` named `project-1.jpg` through `project-4.jpg`, plus `profile.jpg`.
2. Add your resume to `resume/` named `resume.pdf`.
3. In `index.html`, replace the placeholder project titles/descriptions and the About paragraph with your own text.
4. Open `index.html` in a browser to preview.

## To publish
Drag the whole folder into a static host like Netlify or Vercel, or use GitHub Pages; no build step needed.
