uOttawa Housing Portal Redesign

A high-fidelity prototype and React/TypeScript frontend to modernize student housing navigation and make it more secure for both landlords and students. Built during a 6-hour hackathon sprint — 2nd place, SESA Hackathon.

Role
Designer & Developer
Tools
React · TypeScript · Vite · Tailwind CSS · Figma · GitHub
Result
2nd Place, SESA Mini Hackathon

The brief was to identify the risks of putting landlords and students on the same platform, then use the time we had to build a usable prototype of a redesigned, more secure uOttawa student housing portal.

We were advised to prototype in Figma, using Figma/Figma AI to help move faster; it was my first time using the tool, but I picked it up quickly.

Designed a high-fidelity prototype and built a React/TypeScript frontend using REST APIs for user authentication to modernize and make the student housing navigation more secure for both landlords and students.

Architected a responsive interface and managed collaborative feature branches to maintain a clean codebase during a 6-hour development sprint.

Add images/project-1-8.jpg
Design Note

When landlords create an account, they need to verify with a driver's license or government ID — an important step in confirming that whoever is logging in is who they say they are.

Add images/project-1-9.jpg
Design Note

The selling point of this project: after the ID check, we integrated an API call to a lightweight AI that runs a face scan. It displays a 4-digit code that the landlord writes on paper and takes a selfie holding, reinforcing the identity check without giving anyone time to scramble and fake who they are. Once all three steps are complete, they're let into the app. Since scam prevention was central to the brief, this layered, creative security flow set the project apart and helped us come 2nd place at the event.
